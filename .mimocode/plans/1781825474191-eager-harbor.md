# Plan: Fix layout and remove Start.bat

## Problem 1: Stats cut off below table
The infoText and connTable both use dynamic sizing (0, proportion). When the table has many rows, the infoText gets compressed and stats (Upload/Download/Active/Total) are pushed off screen.

## Fix 1: Fixed height for infoText
Give `infoText` a fixed height of **14 lines** so it never gets compressed. The table fills remaining space.

```go
flex := tview.NewFlex().SetDirection(tview.FlexRow).
    AddItem(infoText, 14, 0, false).   // fixed 14 lines
    AddItem(connTable, 0, 1, false)    // fill rest
```
