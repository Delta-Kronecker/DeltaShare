# Plan: Fix Windows independent execution + title + icon

## Root Cause Analysis
1. **FreeConsole+AllocConsole crashes**: tview/tcell caches console handles before our init() reassigns them
2. **CreateProcessW didn't work**: `os.Setenv` may not update Windows env block properly, child doesn't see the flag
3. **Double-click shows empty window**: CreateProcess creates child, parent exits, but child crashes

## Solution: Command-line flag instead of env var
Use `--self` flag to signal self-relaunch. More reliable than env vars.

### Flow:
1. `init()` in console_windows.go checks if `--self` is in os.Args
2. If NO `--self`: we're the original process from PowerShell → use `CreateProcessW` with `CREATE_NEW_CONSOLE` to spawn ourselves with `--self` flag, then `os.Exit(0)`
3. If YES `--self`: we're the relaunched process → just set window title "DeltaShare"
4. Double-click case: Windows already gives own console, `GetConsoleProcessList` returns 1, skip relaunch

### Files to modify:
- `console_windows.go` - rewrite with flag-based approach
- `main.go` - no changes needed (flags are parsed after init)
